# Feltwise · 德州扑克训练桌

一个基于现成浏览器德州扑克项目改造的可直接游玩版本。

## 当前版本

- Solo vs Bots：直接开始游戏
- 完整德州扑克下注流程：盲注、公共牌、边池、摊牌
- 本地保存：刷新后可以继续未完成牌局
- 牌桌教练：新手 / 进阶 / 高手三档
- 边玩边学：轮到玩家时显示行动建议、底池赔率、牌力和解释
- 本局复盘：记录玩家行动，提示高价跟注等常见问题
- PWA / Service Worker：首次访问后支持离线
- GitHub Actions：推送到 main 自动部署 GitHub Pages

## 使用

打开部署后的 Pages 地址，给一个座位输入名字，其余留空让 Bot 自动补位，点击 Start。点击牌桌下方的“教练”打开侧边教练面板。

教练是解释和训练工具，不会自动替你点击，也不连接外部 AI 服务；建议结合自己的判断、位置、有效筹码和对手范围学习。
